# MediCore — Pharmacy Database Management System

MediCore is a Flask-based web application designed to simplify pharmacy operations, including medicine ordering, billing, inventory management, and branch administration.

## Features
- Customer medicine ordering
- Pharmacist prescription verification and billing
- Inventory and stock management
- Purchase and sales reports
- Multi-branch pharmacy management
- Refill reminders and stock alerts

## Technology Stack
- **Backend:** Python, Flask
- **Database:** SQLite, PostgreSQL support
- **ORM:** SQLAlchemy
- **Frontend:** HTML, CSS, JavaScript
- **Testing:** Pytest
